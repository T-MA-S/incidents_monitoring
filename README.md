# Мониторинг ИТ-инцидентов

Учебное Android-приложение на Kotlin (Jetpack Compose, Material 3), выполненное по
лабораторным работам 1–3. Вариант 12 — «Мониторинг ИТ-инцидентов».

## Возможности

- **ЛР1 — интерфейс и навигация:** главный экран со сводкой, список инцидентов,
  экран просмотра, форма добавления/редактирования; демонстрационные данные.
- **ЛР2 — данные:** локальное хранение в Room (SQLite) с сохранением между запусками,
  полный CRUD (добавление, просмотр, изменение, удаление), загрузка справочника
  дежурных сотрудников из REST API (`jsonplaceholder.typicode.com`) с обработкой
  состояний загрузки и ошибки сети.
- **ЛР3 — системная функция:** фотофиксация инцидента камерой устройства с запросом
  разрешения `CAMERA` и обработкой отказа пользователя.

## Структура

```
app/src/main/java/com/example/incidentmonitor/
├── data/               # модели, Room (Entity, DAO, Database), репозиторий, REST API
└── ui/                 # навигация, экраны (главный, список, просмотр, форма, дежурная смена)
```

## Сборка

Требуется JDK 17–21 и Android SDK 35.

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
